# licensedigest-site

Public marketing site for **LicenseDigest** (licensedigest.com), a product of Kummer Ventures LLC.

Static HTML only. This repository deliberately contains **no pipeline code, no customer data, no
prospect lists and no credentials** — those live in the private `kummerventures/licensedigest`
repository. It is public solely so GitHub Pages can serve it on a free plan.

Served by GitHub Pages from the `main` branch, root directory.
